# IT Support Dashboard

## Overview

The primary objectives of this **IT Support Dashboard** are:
- Monitor IT support performance by tracking ticket resolution, agent interactions, and compliance rates.
- Analyze support efficiency through key metrics like **resolution SLA compliance**, **first response compliance**, and **ticket distribution**.
- Identify trends and areas for improvement in **ticket volume**, **agent workload**, and **customer support experience**.

---

## Technology Used

- **Tool**: **Power BI**
- **DAX & Functions**: 
   - **DAX measures** were used to find:
     - Open tickets
     - In-progress tickets
     - Number of resolution days

---

## Steps Taken

1. **Explore Data**:
   - Inspect the dataset for missing and duplicate values.
   
2. **Deal with Missing Values**:
   - Handle missing data using appropriate techniques (imputation, removal, etc.).

3. **Create Visual Representation**:
   - Develop a dashboard using **Power BI** to visualize key performance metrics.

---

## Analysis

### 1. **Ticket Status & Resolution**
- **Total Tickets**: 2,330
- **In Progress**: 400 (17.17%)
- **Open Tickets**: 18 (0.77%)
- **Resolved & Closed**: 81.89% combined
- **Average Resolution Time**: 1.37 days (suggests efficient handling)

### 2. **Ticket Categories & Channels**
- **Top Ticket Topics**:
  - **Product Setup**: 630
  - **Pricing & Licensing**: 525
  - **Feature Request**: 417

- **Report Channels**:
  - **Chat**: 52.96%
  - **Email**: 36.48%
  - **Phone**: 10.56%

### 3. **Compliance & Performance**
- **Resolution SLA Compliance**: 81%
- **First Response Compliance**: 86.65% within SLA (Good, but room for improvement)

### 4. **Geographic Distribution & Trends**
- **Tickets originate from multiple countries**, with high volumes from **Germany**, **UK**, **Italy**, and **Poland**.
- **Ticket volume fluctuates monthly**, peaking in certain months.

## Outcome

- **Reduced average resolution time** and improved **SLA compliance visibility**.
- Empowered **support leads** with actionable insights for continuous performance improvement.
